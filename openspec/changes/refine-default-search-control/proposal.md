## Why

搜索框在未配置自定义搜索引擎时显示“添加搜索引擎”，把低频配置操作放在了高频搜索入口中，也没有准确表达系统会继续使用浏览器默认搜索设置。需要让默认状态与实际搜索行为一致，并降低搜索框内的视觉干扰。

## What Changes

- 浏览器支持默认搜索能力时，默认搜索引擎选择器显示“浏览器默认”，不再显示“添加搜索引擎”。
- 适当压缩桌面端搜索引擎选择器宽度，为搜索输入保留更清晰的主视觉区域。
- 搜索框占位文案精简为“搜索网址或输入关键词”，英文提供等义文案。
- 空闲状态仅显示 Enter 提示；结果面板出现且支持选项导航时再显示上下方向键与 Enter 提示。
- 保留搜索引擎下拉入口，自定义搜索引擎的添加操作继续作为下拉菜单中的次级操作。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `local-link-quick-search`: 明确搜索框默认引擎状态、占位文案及键盘提示的展示要求。

## Impact

- 影响新标签页顶部搜索框、搜索引擎选择菜单、搜索结果面板状态和中英文文案。
- 不改变已有网址匹配、排序、网页搜索和网址直达规则。
- 不新增依赖，不涉及外部 API 或数据迁移。
