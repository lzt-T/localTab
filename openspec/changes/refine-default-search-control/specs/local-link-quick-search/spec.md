## ADDED Requirements

### Requirement: 搜索框默认状态与操作提示
系统 SHALL 在浏览器支持默认搜索能力且用户未选择自定义搜索引擎时，将搜索引擎选择器显示为“浏览器默认”，并使用浏览器默认搜索设置执行网页搜索。系统 MUST 使用简洁且与当前语言一致的占位文案，并根据快速搜索结果面板的状态展示对应的键盘操作提示。添加自定义搜索引擎的入口 SHALL 保留在搜索引擎选择菜单中，不得替代可用搜索引擎的当前状态文案。

#### Scenario: 展示浏览器默认搜索状态
- **WHEN** 浏览器支持默认搜索能力且用户未选择自定义搜索引擎
- **THEN** 搜索引擎选择器显示“浏览器默认”，且不显示“添加搜索引擎”作为当前状态

#### Scenario: 使用浏览器默认设置执行网页搜索
- **WHEN** 浏览器支持默认搜索能力且用户处于“浏览器默认”状态并提交网页搜索
- **THEN** 系统使用浏览器默认搜索设置处理查询

#### Scenario: 展示本地化占位文案
- **WHEN** 搜索框为空且界面语言为简体中文或英文
- **THEN** 系统显示对应语言的“搜索网址或输入关键词”等义文案

#### Scenario: 保持选择器紧凑
- **WHEN** 搜索框以桌面布局展示浏览器默认状态
- **THEN** 搜索引擎选择器仅占用容纳状态文案和下拉标识所需的紧凑宽度，并为输入区域保留主要空间

#### Scenario: 空闲状态展示提交提示
- **WHEN** 搜索结果面板未显示
- **THEN** 搜索框仅展示 Enter 提交提示，不展示上下方向键提示

#### Scenario: 结果状态展示导航提示
- **WHEN** 搜索结果面板显示且其中存在可选择选项
- **THEN** 搜索框展示上下方向键选择和 Enter 执行提示

#### Scenario: 从菜单添加自定义搜索引擎
- **WHEN** 用户展开搜索引擎选择菜单
- **THEN** 菜单将“添加搜索引擎”作为次级操作提供，且不影响当前引擎状态的展示
