## Context

操作指南当前由 `OperationGuide.tsx` 中的静态分段映射和 `src/i18n/resources.ts` 中的双语文案组成，渲染在设置面板已有的可滚动内容区域内。现有实现已经覆盖图标、标题和项目列表，不需要新的交互状态。此次变更的重点是让信息架构和文案准确反映快捷收藏、本地快速搜索、内容整理、Dock、删除及数据管理的现有行为。

## Goals / Non-Goals

**Goals:**

- 按用户要完成的任务重组操作指南，而不是按零散控件动作分类。
- 补齐快捷收藏与本地快速搜索等已存在但未被说明的能力。
- 明确容易混淆的取消固定、删除、快捷收藏和浏览器书签导入边界。
- 保持中英文内容完整对应并统一产品术语。
- 复用当前设置面板和操作指南渲染结构，以最小范围完成修改。

**Non-Goals:**

- 不实现交互式新手引导、步骤高亮、视频、动图或搜索功能。
- 不改变快捷收藏、搜索、拖拽、Dock、删除和数据管理的业务逻辑。
- 不重新设计设置面板导航、尺寸或滚动容器。
- 不扩展新的语言或增加外部文档系统。

## Decisions

### 1. 使用七个任务导向分段

指南按“快捷收藏当前网页、搜索与快速访问、创建和编辑、整理内容、使用 Dock、删除内容、偏好与数据”排序。将快捷收藏放在首位，因为它位于新标签页之外，是最容易被用户遗漏的高价值入口；其余分段遵循从访问、创建、整理到管理和备份的使用路径。

未继续沿用“添加、编辑、拖拽、文件夹”的动作分类，因为这会把同一用户目标拆到多个位置。

### 2. 复用现有静态映射渲染

继续由分段配置保存 `id`、图标、标题翻译键和项目翻译键，并由现有列表统一渲染。新增快捷收藏分段并重新排列现有分段，不引入折叠面板、标签页或组件状态。

这一方案能保持修改集中，也适合当前七个短分段和设置面板已有的纵向滚动方式。

### 3. 文案采用“入口或动作 + 结果”表达

每条说明优先指出用户在哪里操作、执行什么动作以及产生什么结果。只保留影响正确使用的限制，例如快捷收藏仅支持 HTTP(S)、Dock 垃圾桶只取消固定、页面删除需要二次确认；不把指南扩展为完整功能规格。

### 4. 将高风险歧义拆成独立说明

Dock 管理和页面删除使用不同分段。快捷收藏当前单页放在首段，浏览器书签批量导入放在数据分段，并用对照语句说明两者区别。这比依赖顶部统一提示更贴近具体操作上下文，因此移除当前脱离上下文的键盘取消固定强调文案，将它并入 Dock 分段。

### 5. 中英文共享结构并统一术语

中英文使用同一组分段和项目键，保证信息数量与顺序一致。英文统一使用 `category` 对应“分类”，使用 `folder` 对应“文件夹”，使用 `pin` / `unpin` 对应 Dock 固定状态。

## Risks / Trade-offs

- [七个分段可能增加页面长度] → 每条文案保持单一操作重点，并复用设置面板现有滚动区域。
- [指南可能随功能迭代再次过时] → 文案描述稳定的用户行为和入口，避免记录非必要的视觉细节。
- [快捷收藏入口受浏览器工具栏布局影响] → 使用“浏览器工具栏中的 LocalTab 图标”这一通用表述，不绑定特定 Chromium 浏览器菜单样式。
- [删改旧翻译键可能留下未使用内容] → 实现时复用仍适合的键，仅清理由本次映射调整直接产生的孤儿翻译键。

## Migration Plan

本次变更不涉及数据迁移。发布时替换操作指南分段配置与中英文文案即可；如需回滚，恢复原分段映射和翻译资源。
