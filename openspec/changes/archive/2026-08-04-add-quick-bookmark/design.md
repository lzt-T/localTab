## Context

扩展弹窗当前只提供打开新标签页和 GitHub 的入口，没有读取活动标签页或写入网址数据。新标签页已经通过 `categoryService`、`categoryItemService` 和 IndexedDB 管理分类及网址；弹窗与新标签页属于同一扩展源，可以直接复用这些本地服务。各浏览器清单已有 `storage`、`contextMenus`、`search` 和 `favicon` 权限，但没有读取当前页面标题与 URL 所需的 `activeTab` 权限。

## Goals / Non-Goals

**Goals:**

- 让弹窗在一次短流程内完成当前页面预览、分类选择和收藏。
- 在不离开弹窗的情况下，以名称快速创建分类并自动选中。
- 复用现有数据模型、排序规则、UI 基础组件和本地服务。
- 将活动页面访问限制在用户主动打开弹窗所授予的最小范围。

**Non-Goals:**

- 不从弹窗创建或选择网址文件夹。
- 不在快速创建分类时配置图标；完整编辑继续由新标签页负责。
- 不增加键盘快捷键、网页内容脚本或新的右键收藏菜单。
- 不同步到浏览器书签、云端服务或其他设备。
- 不重构现有新标签页链接编辑流程和无关的后台脚本。

## Decisions

### 1. 以扩展弹窗作为快速收藏入口

弹窗在打开时通过 `chrome.tabs.query({ active: true, currentWindow: true })` 获取活动标签页，校验 URL 协议后构造只读的待收藏页面信息。各清单增加 `activeTab`，不申请可持续读取浏览历史的宽泛 `tabs` 权限。

备选方案是使用现有右键菜单或打开新标签页表单。右键链接无法稳定得到目标链接的页面标题，且需要额外设计默认分类；新标签页表单则不能缩短当前操作路径，因此均不作为本次入口。

### 2. 弹窗直接复用本地领域服务

快速收藏通过现有 `categoryService` 读取和创建分类，通过 `categoryItemService.createLink` 将网址追加到分类混排网格末尾。弹窗与新标签页共享扩展源和 IndexedDB，不增加后台消息协议，也不复制一套存储逻辑。

`categoryService.createCategory` 调整为返回创建完成的分类对象，现有忽略返回值的调用保持兼容，弹窗可据此可靠选中新分类。快速创建传入稳定的默认分类图标。

备选方案是在弹窗创建后重新查询分类并按名称匹配。分类名称未要求唯一，这种方式无法可靠定位刚创建的记录，因此不采用。

### 3. 用轻量 Hook 管理弹窗流程

保留 `PopupApp` 负责布局和展示，将活动标签页加载、分类加载、目标分类状态、内联创建状态、重复检查和提交反馈集中在一个具名业务 Hook 中。页面信息和分类均由已有状态直接派生，不建立额外 Store，也不增加无实际消费方的记忆化。

分类选择复用现有 Select、Button 和 Input。选择区域下方提供“创建分类”入口；进入创建态后显示名称输入、确认与取消操作。创建成功后自动选中新分类并返回选择态，待收藏页面信息不重新加载。

快速收藏写入成功后展示成功反馈，并在反馈显示 1 秒后关闭扩展弹窗；等待期间保持提交按钮禁用。重复收藏或写入失败时不关闭弹窗，让用户能够更换分类或重试。

popup 页面使用独立页面标识覆盖全局 `body` 和 `#root` 的 `min-height: 100vh`，使 Chromium 按实际内容自动调整弹窗高度。页面、body 和根节点保留统一深色背景，作为尺寸变化期间的视觉兜底。

### 4. 快速路径不阻塞于网站图标探测

优先使用活动标签页提供的 `favIconUrl`。如果不可用，则使用现有浏览器 favicon 地址生成能力作为回退；图标仍不可用时保存空图标，由现有网址卡片呈现默认视觉。快速收藏不顺序探测多个远程图标地址，避免最长数秒的等待。

### 5. 重复判断属于领域服务

在分类项目服务中提供按“分类范围 + 完整 URL”检查已有网址的能力。分类范围同时包含分类直属网址及其文件夹中的网址；比较活动标签页返回的完整 URL 字符串，不对查询参数、片段或末尾斜杠进行推测性归一化。不同分类之间允许保存相同 URL。

保存前执行重复检查；命中时不写入数据并返回“已收藏”反馈。该规则放在服务层，避免 UI 组件自行遍历和理解文件夹结构。

### 6. 保留弹窗现有次要入口

快速收藏成为弹窗的主要区域；“打开新标签页”和 GitHub 入口继续保留为次要操作。新增文案全部进入现有中英文资源，界面继续沿用当前玻璃表面、雾蓝主行动和 44px 操作目标。

## Risks / Trade-offs

- [某些浏览器内部页不会向扩展暴露 URL 或标题] → 将所有非 HTTP(S) 或信息缺失状态收敛为明确的不可收藏提示。
- [标签页 favicon 可能是空值或短期失效] → 图标不作为提交前置条件，使用浏览器 favicon 地址或现有默认视觉回退。
- [用户快速重复点击提交] → 提交期间禁用主要按钮，并在写入前执行同分类重复检查。
- [直接修改分类创建服务返回类型影响调用方认知] → 保持参数和副作用不变，现有调用方可以继续忽略返回值，仅为新流程暴露已创建实体。
- [popup 可用高度有限且动态内容会改变高度] → 分类创建采用原地轻量输入，popup 页面解除全局视口最小高度限制并保持根背景一致。

## Migration Plan

1. 为 Chrome、Edge 和 Opera 清单加入 `activeTab` 权限；Brave 构建继续复用 Chrome 清单。
2. 部署服务返回值和重复检查能力后接入弹窗流程，不修改 IndexedDB 版本或已有记录。
3. 发布后已有用户数据无需迁移；回滚时移除弹窗快速收藏代码和 `activeTab` 权限即可，已经收藏的链接仍是标准现有记录。
