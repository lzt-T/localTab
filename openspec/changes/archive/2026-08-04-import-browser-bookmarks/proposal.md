## Why

LocalTab 目前只能逐个创建网址或恢复自身 JSON 备份，新用户无法直接迁移浏览器中已经整理好的书签。通过用户主动授权读取浏览器书签，可以在不要求手动导出文件的情况下完成本地迁移，同时保持现有功能与权限彼此独立。

## What Changes

- 在扩展清单中声明可选的 `bookmarks` 权限，不将其加入安装时必需权限。
- 在数据管理中提供“从浏览器导入书签”入口，并在用户主动点击时解释用途、请求权限和读取完整书签树。
- 将浏览器书签层级转换为 LocalTab 分类、文件夹和网址；对超过 LocalTab 两级模型的目录使用可识别的路径名称展平。
- 在写入前展示分类、文件夹、网址及跳过项目的导入预览，由用户确认后追加导入。
- 使用单个 IndexedDB 事务写入全部新增记录，失败时不留下部分导入数据，也不覆盖现有 LocalTab 数据。
- 导入成功、取消或失败后释放 `bookmarks` 权限；整个流程只读取浏览器书签，不创建、修改或删除浏览器原书签。
- 对拒绝授权、API 不可用、空书签树、无效网址和重复网址提供明确反馈，不影响 LocalTab 其他功能。

## Capabilities

### New Capabilities

- `browser-bookmark-import`: 用户通过可选权限读取浏览器书签、预览转换结果并安全追加导入 LocalTab。

### Modified Capabilities

无。

## Impact

- 影响 Chrome、Edge 和 Opera 清单以及复用 Chrome 清单的 Brave 构建，需要增加 `optional_permissions`。
- 新增浏览器书签读取、树形转换、导入计划与批量事务写入能力。
- 扩展数据管理界面、双语文案、操作指南和浏览器 API 类型声明。
- 不新增运行时依赖，不改变现有 IndexedDB 数据结构，也不修改浏览器原书签。
